# IT Help Desk API

FastAPI və SQLAlchemy istifadə olunaraq hazırlanmış IT Help Desk müraciətlərinin (tickets) idarə olunması üçün RESTful backend servisi.

---

## Texnologiya Steki
* **Python 3.10+**
* **FastAPI** — Web API freymvorku
* **SQLAlchemy** — ORM və Verilənlər Bazası idarəetməsi
* **Pydantic v2** — Məlumatların doğrulanması (Validation) və Schema idarəetməsi
* **SQLite / SQL Server** — Verilənlər Bazası
